Projects / NL4AI 2026

Italian fact verification

Alessandro Pucci, Danilo Croce and Roberto Basili
University of Rome Tor Vergata

Research question

If a model has to judge an Italian claim against a supplied passage, when does training for that task help more than increasing the model’s size?

How we tested it

We evaluated models on 2,063 manually validated claim–passage pairs from FEVER-IT. Each passage either supports the claim, contradicts it, or contains too little information to decide. We compared general-purpose models given a few examples with a task-adapted Llama model and two smaller text classifiers.

What we found

Llama 3.1 8B accuracy on the FEVER-IT test set
SettingAccuracy
Few-shot prompting70.67%
LoRA adaptation88.85%

The largest improvement came on claims for which the passage offered insufficient evidence. Among the larger general-purpose models, increasing parameter count did not consistently improve accuracy.
